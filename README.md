## ✨ چرا این پروژه؟

به‌جای ورق زدن کاتالوگ‌های کاغذی و پی‌دی‌اف‌های سنگین، همه‌ی اتصالات فاضلابی پارس پلاست در یک اپلیکیشن سبک جمع شده است؛ با جستجوی فوری و نمایش کامل مشخصات فنی.

## 🚀 امکانات

| قابلیت | توضیح |
|--------|-------|
| 🔍 جستجوی سریع | پیدا کردن محصول در چند ثانیه |
| 🗂️ دسته‌بندی هوشمند | فیلتر بر اساس نوع و سایز |
| 📐 مشخصات فنی | ابعاد، قطر و کاربرد هر قطعه |
| 🎨 رابط مدرن | طراحی ساده و واکنش‌گرا با Flet |
| 🌐 چندپلتفرمی | دسکتاپ، وب و موبایل با یک کدبیس |

## 🛠️ تکنولوژی‌ها

- Python زبان اصلی
- Flet رابط کاربری مبتنی بر Flutter

## ⚡ شروع سریع

# دریافت پروژه
git clone https://github.com/git-abolf/pars-plast-catalog.git
cd pars-plast-catalog

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرا
flet run main.py
اجرا روی مرورگر:

flet run --web main.py
## 📦 ساخت نسخه‌ی نهایی

flet build windows   # ویندوز
flet build apk       # اندروید
flet build web       # وب
